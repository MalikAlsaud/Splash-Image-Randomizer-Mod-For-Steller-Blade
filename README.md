# Splash-Image-Randomizer-Mod

A mod to change the splash image every time Steller Blade runs

[The Mod on Nexus Mods Website] (https://www.nexusmods.com/stellarblade/mods/3164)

# The Mod description from its page

[b][size=5]Description[/size][/b]
[color=#D4D4D8]This mod allows you to place splash images that change the default splash image.[/color]

[color=#D4D4D8]NOTE: [/color][color=#ffff00]Please read the instructions to know how to make the mod work before downloading.[/color]

When you do the instruction, and you start the game, it will flash a CMD screen for a second, don't freak out, it's just running the script.

[b][size=5]Installation[/size][/b]
[size=4][b]Option 1 Vortex (Recommended):[/b][/size]
Use the Vortex Download option since it will place the files in the right place automatically. Read the instructions when you are done installing.

[size=4][b]Option 2 Munally:[/b][/size]
Extract the Zip file, then move what is inside the folder called "Splash" to "Stellar Blade\SB\Content\Splash".
If you own the game on Steam, it would be something like this C:\SteamLibrary\steamapps\common\Stellar Blade\SB\Content\Splash.  Read the instructions when you are done installing.

[b][size=5]instructions[/size][/b]
If you own the game on Steam and you start the game through the Steam launcher, do what is under the [b]Steam [/b]section. [color=#00ff00]However[/color], if you have it as a Non-Steam Game or you run it through Vortex or using any other way, do what is under the [b]Non-Steam Game or through Vortex or another starting method [/b]section.

[color=#d4d4d8][size=4][b]Steam:[/b][/size][/color]
[b][color=#ffff00]If you own the game on Steam[/color][/b][color=#d4d4d8], do this ↓ [/color]
Go to your Steam Library -> Stellar Blade page -> Click on the Settings icon on the right (the spinning wheel) -> Choose Manage -> Choose Browse local files -> Go to SB folder -> Go to Content folder -> Go to Splash folder -> Right-click on RandomSplash -> Copy as path.

After copying the path, do this ↓
[color=#d4d4d8]Go to your Steam Library -> Stellar Blade page -> Click on the Settings icon on the right (the spinning wheel) -> Choose Properties -> Under "LAUNCH OPTIONS" type cmd /c "" and inside the quotation marks press Right-click on the mouse, then click on Paste, then press Space and add %command% (the %command%  will be inside the quotation marks after the what you paste). it will look somethingl ike this cmd /c ""C:\Program Files (x86)\Steam\steamapps\common\StellarBlade\SB\Content\Splash\RandomSplash.bat" %command%".[/color]
[color=#d4d4d8]Then place any pictures you want in the Splashs folder that is inside the Splash folder, which is next to the RandomSplash file. It does not matter the name of the pictures, just make sure they are either jpg or png.[/color]

[size=4][b]Non-Steam Game or through Vortex or another starting method:[/b][/size]
[b][color=#ffff00]If it is a Non-Steam Game[/color][/b], do this ↓
First, go to where your game is installed (the folder that is called Stellar Blade that has the SB file, which starts the game) -> Go to SB folder -> Go to Content folder -> Go to Splash folder -> Right-click on RandomSplash -> Copy as path.

After copying the path, do this ↓
Go to your Steam Library -> Stellar Blade page -> Click on the Settings icon on the right (the spinning wheel) -> Choose Properties -> 
Under "TARGET" press Right-click on the mouse, then click on Paste -> Then under "START IN"  press Right-click on the mouse, then click on Paste then ONLY remove the [color=#ff0000]\RandomSplash.bat[/color], [color=#ff0000]DON'T remove the quotation marks[/color]. So, the "TARGET" will look to something like "C:\Games\Stellar Blade\SB\Content\Splash\RandomSplash.bat", and the "START IN" will look like this "C:\Games\Stellar Blade\SB\Content\Splash"
Then place any pictures you want in the Splashs folder that is inside the Splash folder, which is next to the RandomSplash file. It does not matter the name of the pictures, just make sure they are either jpg or png.

[color=#00ff00]If you put your game as a Non-Steam Game but you started it with Vortex, you must follow the Vortex route or do both.[/color]

[b][color=#ffff00]If it is through Vortex 2.0.0[/color][/b], do this ↓
First, go to where your game is installed (the folder that is called Stellar Blade that has the SB file, which starts the game) -> Go to SB folder -> Go to Content folder -> Go to Splash folder -> Right-click on RandomSplash -> Copy as path.

After copying the path, do this ↓
In Vortex, choose Steller blade from the left panel -> Go to Tools -> press on the "+" sign on the right -> in Target there is a folder icon, press on it then go to where your game is installed (the folder that is called Stellar Blade that has the SB file, which starts the game) -> Go to SB folder -> Go to Content folder -> Go to Splash folder -> and choose RandomSplash.
Then, in Start In, press on the folder icon and go to where your game is installed (the folder that is called Stellar Blade that has the SB file, which starts the game) -> Go to SB folder -> Go to Content folder -> Go to Splash folder, then press Select Folder.
In the name field put what you want, then click on save. After this, click on the 3 dots and click on "Set as default launcher".
Then place any pictures you want in the Splashs folder that is inside the Splash folder, which is next to the RandomSplash file. It does not matter the name of the pictures, just make sure they are either jpg or png.

[b][color=#ffff00]If you are using any other method, like through a shortcut[/color][/b], do this ↓
go to where your game is installed (the folder that is called Stellar Blade that has the SB file, which starts the game) -> Go to SB folder -> Go to Content folder -> Go to Splash folder -> Right-click on RandomSplash -> Copy as path and paste in Target field, you may need to remove the quotation marks. 
And in Start In, place the same path but remove the [color=#ff0000]\RandomSplash.bat[/color]
[color=#ffffff]Then place any pictures you want in the Splashs folder that is inside the Splash folder, which is next to the RandomSplash file. It does not matter the name of the pictures, just make sure they are either jpg or png.[/color]
